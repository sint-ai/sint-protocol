# Settlement

The industrial pack includes a `FactorySettlement` profile so reusable factory
skills, adapters, policy packs, simulation templates, operators, and
maintainers can be attributed without weakening the safety boundary.

Settlement is never a reason to execute a physical action. It is a post-proof
accounting layer that requires:

- simulation evidence
- human approval for T2/T3 actions
- a hash-linked receipt chain
- an execution receipt event

The sample profile is in
[`../examples/pick-place-cell/factory-settlement.sample.json`](../examples/pick-place-cell/factory-settlement.sample.json).
