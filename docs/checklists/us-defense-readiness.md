# U.S. Defense Readiness Checklist

This is an execution checklist, not legal advice. Export-control, corporate, and
security decisions require qualified counsel and the applicable government
authority.

## Corporate And Contracting

- [ ] Delaware corporation, banking, insurance, invention assignment, and IP
      ownership verified.
- [ ] SAM.gov registration active with UEI and CAGE code.
- [ ] NAICS and small-business representations reviewed.
- [ ] Government-contract accounting and timekeeping path selected.
- [ ] Commercial and government data-rights positions documented.

## Export Control

- [ ] Commodity-jurisdiction and ITAR/EAR analysis completed before controlled
      weapons-system integration.
- [ ] Empowered official and registration obligations determined.
- [ ] U.S.-person staffing and access controls documented.
- [ ] Public protocol repository separated from controlled integrations,
      customer data, and technical assistance.
- [ ] Foreign ownership, control, or influence reviewed with counsel.

## Cybersecurity

- [ ] FCI and CUI boundaries documented.
- [ ] NIST SP 800-171 gap assessment and system security plan completed.
- [ ] CMMC Level 2 assessment strategy selected.
- [ ] Incident reporting, media protection, access review, and supplier
      flow-down procedures established.
- [ ] Reproducible builds, signed releases, dependency review, and SPDX SBOM
      generated for each release candidate.

## Classified Work

- [ ] Initial prototypes remain unclassified unless a sponsor requires
      otherwise.
- [ ] Facility clearance pursued only through contract sponsorship.
- [ ] Classified development environment and cleared staffing are not claimed
      before authorization exists.
