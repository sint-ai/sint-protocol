## Security-Relevant Changes

- OWASP conformance claims are now split by invariant layer: transmission integrity, authorization integrity at execution, execution integrity, and intent integrity.
- Intent-layer coverage is explicitly scoped as advisory rather than cryptographic or deterministic enforcement.
- Constraint envelopes that include migration attestation now fail validation unless continuity is verified and the attestation shape is complete.
- Kinetic-envelope review established `KINETIC_CAPACITY_EXCEEDED` as the preferred distinct audit code for physics vetoes, pending fixture completion.
