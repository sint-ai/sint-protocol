single place while the external assessment remains in progress.

## What This Profile Covers

The profile ties together the public artifacts that support AAIF Gate 5 and
OpenSSF readiness:

- security intake and disclosure expectations
- dependency review and SBOM workflow
- signed release-gate reporting
- repeatable conformance evidence
- public gap tracking for remaining readiness work
